# Linked List JS

A JavaScript package for singly and doubly linked lists.

This package will mirror the behavior of the Python `mt-linked-list` package, adapted for idiomatic JavaScript.

## Development

Run the test suite:

```bash
npm test
```

## Planned API

- `Node`
- `SinglyLinkedList`
- `DoublyLinkedList`
- `LinkedList`
- `EmptyValueError`
- `ValueTypeError`
- `CycleDetectedError`

Implementation will be added across focused branches so each pull request remains small and reviewable.
